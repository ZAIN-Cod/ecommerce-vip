# 🛍️ E-Commerce VIP — React Shopping Website

A fully responsive e-commerce website built with React and Tailwind CSS, featuring dynamic product listings, a working shopping cart, and smooth scroll animations.

## ✨ Features

- **Responsive Navbar** with mobile hamburger menu and live cart count badge
- **Animated Hero Section** with entrance animations
- **Dynamic Product Grid** rendered from a data array using `.map()`
- **Scroll Animations** — product cards fade in as you scroll (Intersection Observer)
- **Shopping Cart** — add items, view cart, see total price, and checkout button
- **Fully Responsive Design** — works on mobile, tablet, and desktop
- **Hover Effects & Micro-interactions** throughout the UI

## 🛠️ Built With

- React (Vite)
- Tailwind CSS v4
- JavaScript (ES6+)

## 🎯 Concepts Practiced

- Component-based architecture
- Props and state management (`useState`)
- Side effects and DOM observation (`useEffect`, `useRef`, Intersection Observer)
- Conditional rendering
- Responsive design with Tailwind breakpoints
